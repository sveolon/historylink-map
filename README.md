# HistoryLink Map of Washington

An unofficial, non-commercial map that places essays from [HistoryLink.org](https://www.historylink.org),
the free online encyclopedia of Washington State history, on a map of the state.

- Each pin is one HistoryLink essay. Tap or hover for the title; the link opens the essay on HistoryLink.org.
- The data is only essay number, title and an estimated location. No essay text or images are copied.
- Locations are estimated automatically from titles and public place data (Wikidata, Wikipedia), so some pins are
  approximate or wrong.
- Basemap: © OpenStreetMap contributors.

**Not affiliated with or endorsed by HistoryLink.org.** All essays and titles are © HistoryLink.org.
If HistoryLink, or anyone else, wants this changed or removed, please open an issue in this repository.
